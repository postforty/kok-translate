📖 KokTranslate 사용 설명서

웹 페이지의 궁금한 텍스트를 마우스로 콕! 찍거나 드래그하여 즉시 번역할 수 있는 똑똑한 확장 프로그램입니다.

기본 사용법

  • 전역 단축키: 브라우저 어디서나 Ctrl + Shift + X (Mac: Cmd + Shift + X)를 누르면 번역 모드가 즉시 켜집니다.
  • 또는 팝업 실행: 브라우저 상단의 KokTranslate 아이콘을 누르고 [콕! 번역 모드 켜기] 버튼을 누릅니다.
  • 웹 페이지에서 번역하고 싶은 요소에 마우스를 올리면 보라색 점선과 배경으로 강조됩니다.
  • 원하는 요소를 마우스로 클릭하면 번역 툴팁이 나타납니다.
  • 언제든지 ESC 키를 누르면 번역 모드가 종료됩니다.

🔄 100% 단방향 맞춤 번역

LLM(Gemini)이 혼용 언어나 영단어에 헷갈리지 않도록, 사용자가 지정한 타깃 언어로만 완벽하게 번역합니다.
  • 기본 동작: 어떠한 텍스트를 선택하든 무조건 설정에 지정된 언어(기본: 한국어)로만 확실하게 번역합니다.
  • 혼용 언어 완벽 지원: 원문에 영어나 특수문자가 섞여 있어도 오직 타깃 언어로만 매끄럽게 번역해 냅니다.

🖱️ 드래그 영역 번역 & 엣지 오토스크롤

마우스 드래그 선택 & 자동 스크롤
클릭 한 번으로 선택하기 어려운 긴 문단이나 여러 요소, 표(Table)를 번역하고 싶을 때 사용합니다.
마우스 왼쪽 버튼을 누른 채로 드래그하여 보라색 박스를 그립니다. 드래그 중 화면 위/아래 가장자리에 닿으면 자동으로 스크롤되어 긴 페이지도 한 번에 선택할 수 있습니다. 마우스를 놓으면 박스 안의 모든 텍스트가 번역됩니다.

✨ 편리한 툴팁 기능 (원문 대조 & 드래그 이동)

  • 원문 ↔ 번역문 토글: 툴팁 헤더의 [원문] / [번역] 버튼을 눌러 원문과 번역문을 표, 인라인 코드, 볼드체 서식을 유지한 채 실시간으로 대조할 수 있습니다.
  • 툴팁 자유 이동: 툴팁 상단 헤더를 마우스로 잡고 드래그하면 원하는 위치로 옮길 수 있어 가려진 본문 텍스트를 손쉽게 확인할 수 있습니다.
  • 원클릭 복사: 우측 하단의 [복사] 버튼을 누르면 마크다운 서식이 유지된 텍스트가 클립보드에 복사됩니다.

⚙️ API 키 및 환경 설정 (Options) 안내

확장 프로그램을 사용하려면 Google Gemini API 키를 설정해야 합니다.

  • Gemini API Key: 설정 화면 상단의 [Google 로그인하고 무료 키 발급받기 →] 버튼을 클릭하여 Google AI Studio에서 무료로 발급받아 등록할 수 있습니다.
  • 연결 테스트 (Test Connection): [연결 테스트] 버튼을 눌러 API 키 유효성 및 정상 통신 여부를 즉시 검증할 수 있습니다.
  • Gemini 모델 (Model): 기본값(gemini-3.5-flash-lite) 외에 사용자가 원하는 모델(gemini-2.5-flash 등)을 직접 입력하여 사용할 수 있습니다.
  • 최종 번역 언어 (Target Language): 기본값인 한국어 외에 영어, 일본어, 중국어, 스페인어, 프랑스어, 독일어 등 원하는 도착 언어로 자유롭게 설정할 수 있습니다.
  • UI 언어 (Language): 한국어 및 영어(English) 중 원하는 언어로 UI를 변경할 수 있으며 영구적으로 유지됩니다.
  • 마크다운 서식 뷰어 (Markdown Viewer): 번역 결과의 코드 블록, 목록, 볼드체 등을 구조화된 마크다운 서식으로 볼지 일반 텍스트로 볼지 설정할 수 있습니다. (기본값: 사용)
  • 기본값 초기화 (Reset Defaults): API Key는 안전하게 보존하면서 모델 및 언어 설정을 언제든 기본값으로 원클릭 복원할 수 있습니다.
