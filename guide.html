📖 KokTranslate 사용 설명서

웹 페이지의 궁금한 텍스트를 마우스로 콕! 찍거나 드래그하여 즉시 번역할 수 있는 똑똑한 확장 프로그램입니다.

기본 사용법

  • 브라우저 상단의 퍼즐 아이콘이나 고정된 KokTranslate 아이콘을 클릭하여 팝업을 엽니다.
  • [콕! 번역 모드 켜기] 버튼을 누릅니다.
  • 웹 페이지에서 번역하고 싶은 요소에 마우스를 올리면 보라색 점선과 배경으로 강조됩니다.
  • 원하는 요소를 마우스로 클릭하면 번역 툴팁이 나타납니다.

🔄 양방향 자동 스마트 번역

따로 언어를 설정할 필요 없이 LLM(Gemini)이 문맥을 파악하여 똑똑하게 번역합니다.
  • 기본 동작: 선택한 텍스트가 영어, 일본어 등 외국어일 경우 한국어로 자연스럽게 번역합니다.
  • 반대 동작: 선택한 텍스트가 이미 한국어일 경우 영어로 번역합니다.

드래그로 여러 문장 번역하기

마우스 드래그 선택
클릭 한 번으로 선택하기 어려운 긴 문단이나 여러 요소에 걸친 텍스트를 번역하고 싶을 때 사용합니다.
마우스 왼쪽 버튼을 누른 채로 드래그하여 보라색 박스를 그립니다. 마우스를 놓으면 박스 안에 포함된 모든 텍스트가 번역됩니다.

⚙️ API 키 설정 (필수)

확장 프로그램을 사용하려면 Google Gemini API 키를 설정해야 합니다.

  • 팝업 메뉴에서 [설정] 버튼을 클릭합니다.
  • 발급받은 Gemini API 키를 입력하고 저장합니다.
  • 이제 모든 준비가 끝났습니다! 자유롭게 웹 페이지를 번역해 보세요.
