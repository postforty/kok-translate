📖 KokTranslate User Guide

A smart browser extension that translates any text on a web page instantly with a single point-and-click or drag selection powered by Google Gemini AI.

Basic Usage

  • Global Keyboard Shortcut: Press Ctrl + Shift + X (Mac: Cmd + Shift + X) anywhere in the browser to toggle translation mode instantly.
  • Or via Popup: Click the KokTranslate icon in your browser toolbar and click [Start Point & Click Mode].
  • Hover your mouse over elements you want to translate — they will be highlighted with a purple dashed outline.
  • Left-click the desired element to open the instant translation tooltip.
  • Press ESC anytime to exit translation mode.

🔄 Strictly Unidirectional AI Translation

The Gemini LLM strictly translates the text into your explicitly chosen target language, completely eliminating mixed-language distraction:
  • Default Behavior: Automatically and consistently translates any selected text into the target language chosen in the settings (default: Korean).
  • Mixed-Language Support: Accurately translates text into the target language even if the source contains a mix of English, special characters, or other languages.

🖱️ Marquee Drag Selection & Edge Auto-Scroll

Mouse Drag Selection & Auto-Scroll
Used when you want to translate multiple paragraphs, articles, or complex page sections at once.
Hold the left mouse button and drag across the page to draw a purple box. The viewport will automatically scroll as you approach the top or bottom edges, allowing you to select long pages seamlessly. Releasing the mouse button will capture and translate all text contained within the area.

✨ Tooltip Enhancements (Source Toggle & Drag to Move)

  • Source ↔ Translation Toggle: Click [Source] / [Translate] buttons in the tooltip header to compare original and translated content while preserving markdown tables, code, and bold styling.
  • Draggable Tooltip: Grab and move the tooltip by its top header to any position on the screen to view obstructed background text.
  • One-Click Copy: Click the [Copy] button at the bottom right to copy formatted markdown text directly to your clipboard.

⚙️ Extension Settings (Options)

To use translation features, you need a Google Gemini API Key (Free via Google AI Studio).

  • Gemini API Key: Click the [Sign in with Google & Get Free API Key →] button on the options page to generate your free API key from Google AI Studio in seconds.
  • Test Connection: Click the [Test Connection] button to verify API key validity and model communication instantly.
  • Gemini Model: Specify custom model IDs (e.g. gemini-2.5-flash) in addition to the default (gemini-3.5-flash-lite).
  • Target Language: Choose your preferred translation language (Korean, English, Japanese, Chinese, Spanish, French, German, etc.). The extension strictly uses this language for all translations.
  • UI Language: Switch interface between Korean and English permanently.
  • Markdown Viewer: Choose whether to render translation results with markdown formatting (code blocks, bold, lists) or plain text. (Default: Enabled)
  • Reset Defaults: Restore model and language to default values with a single click while safely keeping your API key.
