# 콕! 번역기 (KokTranslate)

웹페이지의 텍스트를 **콕!** 찍거나 드래그하여 바로 번역하는 LLM 기반 크롬 확장 프로그램입니다.

[English Documentation](README.md)

---

## 🌟 주요 기능

* **🔑 Google AI Studio 무료 키 원클릭 발급 연동**: 설정 페이지 내 바로가기 버튼을 통해 누구나 1분 만에 무료 Gemini API 키를 발급받아 손쉽게 등록할 수 있습니다.
* **⚡ 전역 단축키(Global Shortcut) 지원**: 마우스로 아이콘을 누를 필요 없이 언제 어디서나 `Ctrl+Shift+X` (Mac: `Command+Shift+X`) 단축키로 번역 모드를 즉시 켜고 끌 수 있습니다.
* **직관적인 요소 선택 (DOM Hover & Highlight)**: 번역 모드를 켜고 마우스를 올리면, 번역될 HTML 요소가 보라색 점선 박스로 강조 표시됩니다.
* **클릭 한 번으로 번역 (Point & Click Translation)**: 강조된 요소를 클릭하면 해당 텍스트를 즉시 번역하여 마우스 위치에 툴팁으로 보여줍니다.
* **드래그 영역 번역 & 엣지 오토스크롤 (Marquee Selection & Auto-Scroll)**: 마우스로 원하는 영역을 드래그하여 여러 요소의 텍스트를 한 번에 번역하며, 화면 위/아래 끝에 닿으면 자동으로 스크롤되어 긴 웹페이지도 한 번에 선택할 수 있습니다.
* **🔄 원문 ↔ 번역문 실시간 상호 대조 (Source / Translation Toggle)**: 번역 툴팁 상단의 `[원문]` / `[번역]` 토글 버튼을 통해 원문과 번역 결과를 즉시 번갈아 가며 확인할 수 있습니다.
* **📝 원문 & 번역문 마크다운 서식 뷰어(Markdown Viewer)**: Gemini 번역문뿐 아니라 **웹페이지 원문의 표(`<table>`), 인라인 코드(`<code>`), 굵은 글씨(`<strong>`), 목록 구조**를 원본 그대로 보존하여 깔끔하고 예쁜 마크다운 서식으로 렌더링합니다.
* **🖐️ 툴팁 자유 이동 (Draggable Tooltip)**: 툴팁 상단 헤더를 마우스로 잡고 원하는 위치로 자유롭게 이동시킬 수 있어 본문 텍스트를 가리지 않고 편안하게 읽을 수 있습니다.
* **🔌 API 연결 테스트 (Test Connection)**: 옵션 페이지에서 API 키와 모델의 정상 통신 여부를 `[연결 테스트]` 버튼으로 즉시 검증할 수 있습니다.
* **🔒 강화된 보안 및 안정성**: API 키를 안전한 공식 헤더(`x-goog-api-key`)로 전송하고, Gemini 공식 `system_instruction` 필드를 분리 적용하여 지침 준수율을 극대화했습니다.
* **LLM 기반 강제 단방향 번역**: Gemini API를 사용하여 사용자가 설정한 지정 타깃 언어로만 100% 번역을 수행하여 언어 혼동이나 오작동 문제를 원천 차단합니다.
* **최종 번역 언어(Target Language) 선택**: 기본값인 한국어 외에 영어, 일본어, 중국어, 스페인어, 프랑스어, 독일어, 러시아어, 베트남어, 힌디어 등 원하는 타깃 언어를 직접 지정할 수 있습니다.
* **커스텀 Gemini 모델 지원**: 기본 모델(`gemini-3.5-flash-lite`) 외에 사용자가 원하는 최신 Gemini 모델 ID를 직접 입력하여 설정할 수 있습니다.
* **다국어(i18n) UI 지원**: 한국어와 영어(English) UI 및 사용 설명서를 기본 지원하며, 설정에서 언어를 변경하거나 시스템 언어에 맞춰 자동 감지됩니다.

## 🚀 설치 방법

1. 이 저장소를 클론하거나 코드를 다운로드하여 폴더 압축을 풉니다.
2. 크롬 브라우저에서 주소창에 `chrome://extensions/`를 입력하여 **확장 프로그램 관리** 페이지로 이동합니다.
3. 우측 상단의 **개발자 모드**를 켭니다.
4. 좌측 상단의 **압축해제된 확장 프로그램을 로드합니다.** 버튼을 클릭합니다.
5. 소스코드가 있는 `kok-translate` 폴더를 선택하여 불러옵니다.
6. 브라우저 우측 상단의 퍼즐 모양(확장 프로그램) 아이콘을 눌러 **KokTranslate**를 핀(고정) 처리하여 쉽게 사용할 수 있도록 합니다.

## ⚙️ 설정 방법 (API 키 및 모델/언어 설정)

번역 기능을 사용하기 위해서는 **Gemini API Key**가 반드시 필요합니다.

1. 브라우저 툴바에서 콕! 번역기 확장 프로그램 아이콘을 클릭한 뒤 **설정** 버튼을 누릅니다. (또는 아이콘 우클릭 -> 옵션)
2. 상단의 **[Google 로그인하고 무료 키 발급받기 →]** 버튼을 클릭하여 Google AI Studio에서 무료 API 키를 발급받습니다.
3. 다음 항목들을 설정하고 **저장하기**를 클릭합니다:
   - **Gemini API Key**: 발급받은 API 키 입력 (눈 아이콘을 클릭하여 비밀번호 표시/숨기기 가능)
   - **연결 테스트**: `[연결 테스트]` 버튼을 눌러 API 키 유효성 및 정상 작동 여부 즉시 확인
   - **Gemini 모델 (Model)**: 사용할 모델 ID 입력 (기본값: `gemini-3.5-flash-lite`)
   - **최종 번역 언어 (Target Language)**: 번역될 목표 언어 선택 (기본값: `한국어`, 영어, 일본어, 중국어, 스페인어, 힌디어 등 선택 가능)
   - **UI 언어 (Language)**: 설정 화면 및 툴팁 UI 언어 선택 (자동 감지 / 한국어 / English)
   - **기본값 초기화**: API 키는 보존하면서 모델과 언어 설정을 기본값으로 원클릭 복원

## 🖱️ 사용 방법

1. **번역 모드 시작 (2가지 방법)**:
   - 단축키 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd> (Mac: <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd>)를 누릅니다.
   - 또는 툴바의 콕! 번역기 아이콘을 누르고 **콕! 번역 모드 켜기** 버튼을 클릭합니다.
2. **요소 클릭 번역:** 번역을 원하는 텍스트 위로 마우스를 올려 보라색 점선 박스가 표시되면 한 번 클릭합니다.
3. **드래그 영역 번역:** 여러 문단이나 테이블을 한 번에 번역하려면 마우스 왼쪽 버튼을 누른 채 드래그합니다. 화면 상/하단 가장자리에 마우스를 대면 자동으로 스크롤됩니다.
4. **결과 확인 및 원문 토글:**
   - 마우스 커서 위치에 번역 툴팁이 나타납니다.
   - 툴팁 헤더의 **`[원문]`** 버튼을 누르면 원본 마크다운 구조(표/코드 서식 유지)를 확인할 수 있으며, **`[번역]`** 버튼으로 다시 전환할 수 있습니다.
   - 툴팁 상단 헤더를 마우스로 잡고 드래그하여 원하는 화면 위치로 옮길 수 있습니다.
   - 우측 하단의 **복사** 버튼으로 텍스트를 클립보드에 복사할 수 있습니다.
5. **번역 모드 종료:** 키보드의 <kbd>ESC</kbd> 키를 누르거나 툴팁 바깥 영역을 클릭하면 번역 모드가 종료됩니다.

## 📂 프로젝트 구조

* `manifest.json`: 확장 프로그램 메타데이터 및 권한/전역 단축키 정의 (Manifest V3)
* `_locales/`: 브라우저/스토어 표준 다국어 메시지 (`ko`, `en`)
* `i18n.js`: 런타임 통합 다국어 모듈 및 DOM 자동 바인딩 로직
* `popup.html` / `popup.js`: 확장 프로그램 팝업 UI 및 스크립트 실행 제어
* `options.html` / `options.js`: 환경 설정 페이지 (API 키, 모델 ID, UI 언어, 연결 테스트 및 초기화)
* `guide.html` / `guide_en.html`: 한국어 및 영문 사용자 설명서
* `content.js`: 웹페이지 DOM 호버 하이라이트, 마퀴 드래그 선택, 엣지 오토스크롤 및 툴팁 드래그/토글 UI
* `background.js`: Service Worker 백그라운드 스크립트, 전역 단축키 핸들러 및 Gemini API 보안 통신
